What to include

This single address covers all enquiries -- general questions, a tool that isn't working as expected, and privacy or data-handling questions about the Privacy notice. To help us respond quickly, mention which tool you were using and, if relevant, roughly what size and format the file was (please don't attach the file itself if it contains sensitive information).

Reporting a problem with a tool

If a conversion fails or the result looks wrong, these details help us find the cause quickly:

  • the tool you used, for example PDF to Word or Merge PDF;
  • the file type and its approximate size and number of pages;
  • the exact message shown on the page, if there was one;
  • what you expected and what you got instead;
  • your device and browser, for example "Android phone, Chrome".

Before you write: common answers

  • Upload limits. Each conversion accepts up to 50 MB in total. Image tools take up to 20 images at a time, and PDF to JPG, PDF to PNG and PDF to PPT convert up to 50 pages at a time; for a longer PDF, use Split PDF first.
  • Password-protected PDFs. A PDF that needs a password to open can't be converted. Remove the password in the program that created it, then try again.
  • Scanned PDFs. A scanned page is a picture of text, so PDF to Word can't turn it into editable text. Our guide Text-based vs scanned PDFs explains the difference and what to do with a scan.
  • More help. Our guides answer common questions about file formats, and each tool page has its own FAQ.
