# Reporting a problem

If you find a problem with KuickKonvert -- a bug that exposes data, a way to get round the upload or rate limits, a file that gets past the type checks, or anything else that could affect visitors or their files -- please email **info@kuickkonvert.com**.

Please include:

- which page or tool is affected (for example `/tools/merge-pdf`);
- what you did, what you expected and what happened instead;
- the date and time, and your browser and device;
- if a file triggers it, a description of the file. Please don't send files that contain personal or confidential information.

Please report it privately by email first, rather than in a public GitHub issue, and give us a reasonable time to fix it before you share details publicly.

We'll reply to confirm we've received your report and let you know what we're doing about it. KuickKonvert is run by one person, Shahid Iqbal, so please allow a few working days. There is no paid bug-bounty programme.

## Scope

- The live site, https://kuickkonvert.com, and the code in this repository.
- Not in scope: the hosting and network providers (Render, Cloudflare) and third-party services such as Google Analytics. Please report problems in those directly to them.

## Supported version

Only the current `main` branch, which is what runs on the live site, is maintained.
